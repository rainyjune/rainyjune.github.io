analyse-an-android-tv-live-streaming-app

  1. Play the m3u8 player in a web player

This live streaming app supports CCTV and many other channels that are popular in China. I am trying to find out how it works and why it can decode CCTV videos correctly.

I am not experienced in Android development, so I have decided to choose another approach - capturing the network traffic on the Android devices.

First I set up the environment with Fiddler and make it listen to traffic from my Android phone.

In order to inspect the server APIs more easily, I also installed Postman.

First, a HTTP GET request to https://gongdian.top/tvbox/okpg/feiyang.txt is made to fetch all the TV channels and their live streaming URL, the response is like:

The interesting thing is that most URLs above use http://127.0.0.1 as their host instead a public domain (e.g: example.com).

It seems the application has set up a web server on my Andoird device. Let’s send a request to the first URL with the hostname replaced with the real IP address in Postman, for example http://192.168.0.101:35456/gaoma/cctv1.m3u8, it returns something like:

What will happen if If I visit the first segment URL: http://192.168.0.101:35456/gaoma/cctv1.m3u8?ts=http://liveali-tpgq.gaoma.tv/live/30a8228c89a864b186be13047a4b3b60_36963.ts?wsSecret=14bed998dc0d0022ff490ff03a65d40e&wsTime=1737545684 on my browser?

A file will be download and saved as a .m3u8 file. I changed the extension from .m3u8 to .ts, and it can be play in a video player!

Play the m3u8 player in a web player

We can embed the URL in a JavaScript player, such as hls.js or Clappr, however, the remote server does not support CORS. In order to play it in our local computer, we need to install a browser extension to disable CORS policy in the browser, I recommend Allow CORS: Access-Control-Allow-Origin.
